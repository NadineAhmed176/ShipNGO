# ShipNGO 🧡

**ShipNGO** is an e-commerce and donation platform that brings shopping, donations, and product swapping together in one place.

The project focuses on providing users with a simple shopping experience while also encouraging reuse and community support.

## ✨ Main Features

- **Product Browsing:** Explore and view available products.
- **Shopping Cart:** Add, remove, and manage products before checkout.
- **Wishlist:** Save products for later.
- **User Authentication:** Support user accounts and profile management.
- **Guest Shopping:** Browse and use shopping features as a guest.
- **Donations:** Support donation-related activities through the platform.
- **Product Swapping:** Provide a way for users to exchange products.
- **Membership Benefits:** Includes a 10% member discount.

## 🛠️ Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery
- Local Storage

**Backend**
- PHP
- Laravel
- SQLite

## 🏗️ Project Structure

The project is organized into two main parts:

- **Frontend:** Handles the user interface and shopping experience.
- **Backend:** Uses Laravel to handle server-side functionality and database operations.

The backend includes database migrations and application routes.

## 🎨 UI & Design

- Dark premium interface.
- Liquid Glass-inspired visual style.
- Orange accent color (`#E87722`).
- Egyptian Pound (EGP) as the displayed currency.
